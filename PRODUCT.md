# DropSauce · local reading

The primary task is to open a book already on the device and resume reading. The library, favorites, history and bookmarks are different ways back to that content. Import and backup use system document pickers. Reading statistics describe data stored on this device. Speech uses the installed Android TTS service with an offline voice. No account, online discovery or update prompt belongs on these screens.

Design for both a short visit (resume, search, find a bookmark) and a long uninterrupted reading session. A book without a cover, a chapter with a very long name and an empty collection are normal states. Preserve the existing bird illustration and its window-relative center when changing tabs.
